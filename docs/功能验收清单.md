### MCP 接入（9 个工具）

在 Claude Desktop / Cursor / Cline 里配置（设置页可一键复制）：

```json
{
  "mcpServers": {
    "invoice-assistant": {
      "command": "<python路径>",
      "args": ["<发票助手>/src/mcp_server.py"]
    }
  }
}
```

| 工具 | 作用 |
| :--- | :--- |
| `invoice_summary` | 汇总统计 |
| `invoice_list` | 列表查询（可按状态/关键字） |
| `invoice_get` | 单张详情 |
| `invoice_raw_text` | 取原文（PDF / 铁路票 ZIP 都支持） |
| `invoice_rescan` | 重新扫描 |
| `invoice_rules_list` | 查看修复规则 |
| `invoice_rule_add` | 新增修复规则 |
| `invoice_rule_delete` | 删除规则 |
| `invoice_export` | 导出 Excel |

接上之后可以直接说：「帮我看看有没有金额没读出来的发票」「总共多少钱」「导出表格」。

## 三、本轮修掉的 4 个真实 bug

| 问题 | 原因 | 修法 |
| :--- | :--- | :--- |
| 铁路票 ZIP 取原文报错 | 只支持 PDF | 增加 ZIP → OFD → XBRL 解析路径 |
| 重新扫描超时 | 扫描 80 个文件要 40 秒，同步接口超时 | 改异步任务 + 轮询状态 |
| 前端导出按钮无效 | 令牌异步加载，点击太快时为空 | 加 `ensureToken()` 前置等待 |
| 总金额在 preview 空白 | openpyxl 只写公式不写值 | 保存后回填 `<v>` 缓存 + `fullCalcOnLoad` |

## 四、已知限制

| 项 | 说明 |
| :--- | :--- |
| 扫描耗时 | 80 个文件约 40 秒（每个 PDF 调一次 pdftotext），已改为异步不阻塞 |
| 分类持久化 | 分类目前存在页面状态里，刷新后需重新分配（导出时会带上） |
| 图片/扫描件 | 暂不支持 OCR，会标为「待确认」 |
| exe 打包 | onedir 版可运行，onefile 因临时目录权限受限不可用 |
